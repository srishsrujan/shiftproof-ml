# Failure log

The training pipeline creates `reports/failure_analysis.csv` with at least 20 analysed mistakes when the test set contains at least 20 errors. Review the rows and add human comments before final submission.

Suggested fields for manual review:

- student_id
- actual placement-ready label
- predicted probability
- confidence
- branch and graduation cohort
- academic and aptitude scores
- technical and communication scores
- project, coding, and internship experience
- error type
- human interpretation
- possible data or model improvement
